# ADR-001 — Teams Meeting Companion

The service separates visible Teams calling presence, Graph transcript retrieval, grounded AI extraction, and user-approved task publishing. Service-hosted media is used without raw-media access. `ITranscriptSource`, `IInsightExtractor`, and `ITaskPublisher` keep tenant integrations replaceable.

Joining requires explicit confirmation. Publishing requires a version hash matching the reviewed draft, preventing stale approvals. Real Graph, durable queue, Entra, AI, storage, retention, and a concrete task-system adapter remain tenant configuration work.
